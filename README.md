# 🗺️ Aplicação Mapa

Aplicação desenvolvida para gerenciamento e visualização de informações relacionadas a **localizações em um mapa**.

O projeto permite trabalhar com dados geográficos de forma integrada a uma aplicação, possibilitando o cadastro, consulta e gerenciamento das informações utilizadas pelo sistema.

## 🚀 Funcionalidades

* 🗺️ Visualização de localizações em um mapa
* 📍 Cadastro de pontos/localizações
* 🔎 Consulta de informações cadastradas
* ✏️ Atualização de dados
* 🗑️ Remoção de registros
* 💾 Persistência das informações
* 🔗 Integração entre a aplicação e o banco de dados

## 🛠️ Tecnologias

* **Banco de dados**
* **SQL**
* **Java**
* **Git**
* **GitHub**

## ⚙️ Como executar

### 1. Clone o repositório

```bash
git clone https://github.com/JuanRodrigues-Dev/Disciplina_Banco_de_Dados_II.git
```

### 2. Acesse o projeto

```bash
cd Disciplina_Banco_de_Dados_II
```

### 3. Abra a pasta da aplicação

Entre na pasta `aplicacaomapa` e abra o projeto na IDE utilizada para o desenvolvimento.

### 4. Configure o banco de dados

Configure a conexão com o banco de dados utilizado pela aplicação e execute os scripts necessários para criação das tabelas e inserção dos dados.

### 5. Execute a aplicação

Inicie a aplicação pela IDE e utilize as funcionalidades disponíveis no sistema.

## 🧩 Funcionamento

A aplicação utiliza uma estrutura de integração entre **interface, lógica da aplicação e banco de dados**.

O usuário interage com o sistema para consultar ou manipular informações de localização. Essas operações são processadas pela aplicação e os dados são armazenados ou recuperados do banco de dados.

```text
             ┌─────────────────┐
             │      Usuário     │
             └────────┬────────┘
                      │
                      ▼
             ┌─────────────────┐
             │   Aplicação     │
             └────────┬────────┘
                      │
                      ▼
             ┌─────────────────┐
             │  Banco de Dados │
             └─────────────────┘
```

## 🎯 Objetivo

O projeto tem como objetivo desenvolver uma aplicação capaz de trabalhar com **dados de localização**, aplicando conceitos de desenvolvimento de software, manipulação de dados e integração com banco de dados.
